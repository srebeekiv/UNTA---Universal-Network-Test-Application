# UNTA - Universal Network Test Application

Android-измеритель интернета: скорость вход/исход напрямую и через прокси (socks4/5, http/https, с авторизацией),
сведения о Wi-Fi и мобильной сети, координаты, внешний IP с гео. Каждое измерение сохраняется двумя файлами:
машинным JSON и читаемым txt (в разных папках), чтобы историю можно было синхронизировать через Syncthing.

Проект общественное достояние (Unlicense): копируйте, форкайте, меняйте как угодно.

Скачать: [Releases](../../releases/latest), файл `UNTA-X.Y.apk`.
